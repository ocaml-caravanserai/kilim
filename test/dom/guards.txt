The guards of kilim.browser, kilim.web, kilim.router.browser,
kilim.http.browser, kilim.websocket.browser and kilim.storage.browser and
their tests (design section 14)

windtrap runs only native code, thus it makes no mutant of src/browser,
src/web and src/router/browser. Each line gives one guard (file, function,
condition) and the test that fails when the guard changes: replace the
condition with true or with false (or remove the call), then run `dune test
--force test/dom test/browser test/loader`. A line "EXPECT EXCEPTION" in the
output is not a failure: look for "FAILED". The tests with D are in
test/dom/test_dom.ml. The tests with W are in test/dom/test_web.ml (W4 to W6
in test_fut.ml, W7 in test_router.ml). The tests with H are in
test/browser/test_browser.ml. The other names are the scenarios of
test/loader/run.mjs.

A test "in Firefox" or "in WebKit" runs only in the dev shell `browsers` of
flake.nix (Playwright): in `nix develop .#browsers`, run `dune build --force
@test/dom/browsers @test/loader/browsers`. In the default shell, these rules
write "SKIP: no Playwright". The other tests run in Chrome.
